# 鲸鱼娘桌宠（纯桌宠版）

⚠️ **重要：本 exe 是「纯桌宠」** —— 只有鲸鱼娘动画、喂食/玩耍/成长，
**不含余额查看、每轮花费、DSH 状态联动**。

## 想要完整功能？

完整版（余额 / 每轮花费 / 今日已用 / DSH 联动）需要装 DSH 插件，一条命令：

```sh
dsh plugin --profile web add github:xiaoju-1229/dsh-whale-pet-balance
```

详见 [README](https://github.com/xiaoju-1229/dsh-whale-pet-balance#readme)。

## 文件说明

- `WhalePet-PetOnly-Portable-*.exe`：**便携版**，免安装，双击即用
- `WhalePet-PetOnly-Setup-*.exe`：**安装版**，需安装

> 只是想当桌面桌宠玩 → 下载便携版即可。需要余额等完整功能 → 请用 DSH 插件版。
